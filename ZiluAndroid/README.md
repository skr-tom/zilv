# 自律 Android MVP

这是第一版 Android Studio 项目源码，使用 Kotlin + Jetpack Compose。

## 当前实现
- 新建每日任务：名称 + 目标分钟数
- 开始 / 暂停 / 继续计时
- 达标立即显示绿色；未达标显示红色
- 任务数据本地保存
- 每日 00:00 安排重置广播；设备重启后重新安排
- 计时根据开始时间戳计算，退出页面后再次打开仍可恢复计时状态

## 打开方式
1. 安装 Android Studio（建议稳定版）。
2. 解压本项目，在 Android Studio 中选择 Open，打开 `ZiluAndroid` 文件夹。
3. 等待 Gradle Sync 完成。
4. 连接 Android 手机并开启 USB 调试，点击 Run。

## 重要说明
- 本项目是可继续开发的 MVP 源码，不是已签名 APK，也尚未在你的设备上编译验证。
- Android 12 及以上设备可能需要在系统设置中允许“闹钟和提醒”精确闹钟权限；若未授权，系统会使用非精确备用闹钟，不能保证恰好在 00:00 触发。
- 历史记录目前已在本地归档，但尚未提供历史日历/统计页面。下一版应增加历史浏览、编辑/删除任务、通知和完善的精确闹钟权限引导。
- 为保证准确性，计时按系统时间戳计算；用户手动修改系统时间可能影响计时。
