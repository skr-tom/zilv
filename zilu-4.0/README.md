# 自律 4.0

Android + Jetpack Compose。页面固定五个：**每日任务、长期计划、日历、每日小记、设置**。
专注模式不占导航页，点任务的「开始」后自动进入全屏专注。

---

## 本次升级做了什么

### 1. 通知（重点修复）

之前的推送不生效，主要原因有四个，已逐项处理：

| 问题 | 现象 | 现在的做法 |
| --- | --- | --- |
| 通知小图标用的是系统资源 `android.R.drawable.*` | 在 Android 8+ / 国产 ROM 上被渲染成白块或直接不显示 | 自绘白色沙漏矢量图 `ic_stat_zilu.xml`，并把沙漏 Logo 作为大图标显示在通知右侧 |
| 提醒渠道重要性是 `LOW` | 通知被折叠到通知栏底部，不弹横幅、锁屏看不到 | 「任务截止提醒」「专注完成」都改为 `IMPORTANCE_HIGH`：响铃 + 振动 + 悬浮横幅 + 锁屏可见 |
| 沿用了旧渠道 ID | 用户曾经关掉过渠道，重建同名渠道不会恢复 | 渠道 ID 全部换成 `_v4`，并自动清理旧的 `_v2` 渠道 |
| 只用 `SCHEDULE_EXACT_ALARM` | 用户没去设置里手动授权时，退化成不精确闹钟，Doze 下可能延迟十几分钟 | 增加 `USE_EXACT_ALARM`（Android 13+ 系统直接授予，不用用户操作），无权限时仍会降级而不是丢闹钟 |

另外：

- 提醒通知的 ID 按任务固定，不会每天堆一条。
- 设置页新增**通知自检面板**：通知权限、两个渠道是否被关、精确闹钟、电池优化，逐项显示状态并提供「去开启」按钮；还有「发一条测试通知」可以立刻验证。
- 专注时的常驻通知加了 `FOREGROUND_SERVICE_IMMEDIATE`，切后台后立即出现在通知栏（不会延迟 10 秒），并带一个「退出专注」按钮。
- 通知里带 `USAGE_ALARM` 音频用途，静音/勿扰下更容易穿透。

### 2. 专注中途退出按秒扣时

任务现在按秒存 `durationSeconds`（计划时长）和 `remainingSeconds`（剩余时长）。

- 计划 1 分钟，专注 30 秒后退出 → 任务剩 `0:30`，任务卡片显示「已做一部分，还剩 0:30」，按钮变成「继续」。
- 下次点「继续」从 30 秒接着计时，不会重新从 1 分钟开始。
- 正常走完才写入完成记录，并把时长复原，第二天照常。

### 3. 提醒时间改为手动输入

任务对话框里的提醒时间不再是滚轮，而是「__ 时 : __ 分」两个数字输入框，会校验 0~23 / 0~59，填错时保存按钮禁用并提示。

### 4. 长期计划改成三级

```
文件夹（第一级，每个文件夹一套颜色）
└── 计划（第二级，嵌在文件夹卡片里）
    └── 子计划（第三级，唯一可以设「预完成时间-月-日」的一层）
```

- 二级计划直接列在一级文件夹卡片内部，点计划展开第三级子计划。
- 只有子计划有「月 / 日」手动输入框，可以为空；过了日期会标红「已逾期」。
- 文件夹有配色选择（8 套），卡片底色、图标、进度条都跟着变。

### 5. 日历

- 月历卡片：月份可前后翻页，点日期行可跳到任意年月，周一为一周第一天，今天红色、选中高亮。
- 每个日期格子里最多显示两条当天待办的彩色标签（颜色和下方卡片一致），超过显示 `+N`。
- 下方待办卡片：左侧彩色拖拽把手 + 浅色底 + 右侧方形勾选框。
- **上下拖动**：按住左侧色条拖动即可调整顺序，松手后写入顺序。
- **完成后自动沉底**：勾选的待办右侧显示绿色 ✓，并自动排到列表最下面，未完成的往上走。
- 长按标题可以删除该条待办。

### 6. 每日小记

- 去掉了日期滚轮。打开就是今天，写完自动保存（停止输入 0.6 秒落盘）。
- 下方是「往期小记」列表，按日期倒序，点任意一天就打开那天的内容继续写。
- 不是今天时会显示「回到今天」。

## 构建

用 Android Studio 打开 `zilu-4.0` 根目录（不是 `app`），等待 Gradle Sync 完成后
**Build > Build Bundle(s) / APK(s) > Build APK(s)**。

- 需要 JDK 17（Android Studio 自带）、compileSdk 35。
- 仓库里没有放 `gradle-wrapper.jar`，命令行 `./gradlew` 需要先执行一次 `gradle wrapper`；
  直接用 Android Studio 构建则不受影响。
- 旧版 APK 的签名密钥未知，如果新包签名不同，需要先卸载旧版本再安装。

## 装好之后必须做的三件事（国产 ROM 尤其重要）

1. 首次启动点「允许」通知权限。
2. 设置页 →「通知与提醒」→ 逐项查看，红叉的项目点「去开启」，最后点「发一条测试通知」确认能收到。
3. 小米 / 华为 / OPPO / vivo 再到系统设置里给「自律」打开**自启动**、**后台弹出界面**，电池策略选**不限制**。

## 数据兼容

存储 key 换成 `zilu_v4`。首次启动会自动读取旧的 `zilu_v2` 数据并迁移：

- 旧任务的「分钟」转成秒级时长；
- 旧计划统一放进一个叫「我的计划」的文件夹，旧的子目标转成子计划，并把原计划的截止日期带到子计划上。

微信 / QQ 真实 OAuth 登录仍需要官方 AppID 与签名配置，当前保留入口与离线模式，不会伪装已登录。
